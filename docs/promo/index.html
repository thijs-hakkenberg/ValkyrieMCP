Arkham · Confidential
Arkham, Massachusetts
the 13th of October, 1926

My dear colleague,

You asked me how the scenarios came to be written. I cannot fully explain it. I spoke to the machine of a lighthouse keeper who vanished, of a basement that floods only at the new moon, and of a thing beneath the pier that counts the rounds until it rises.

By morning the file lay in the Editor folder, finished. Every tile was placed and every event branched and joined again. The monster's spawn trigger was tied to the mythos rounds, as I had asked. Not one reference was broken. The validator reported zero errors, and I have never found that comforting.

Valkyrie opened it at once. My players have not slept properly since.

— Prof. H. W. Armitage (ret.)

From whisper to tableThe Ritual

✦

Speak the Premise

“A fishing village, a missing priest, three hours before high tide.” That much is enough to begin. Invoke /scenario or hand it to the familiar.

Lay the House

Tiles are chosen from the real game catalog by what is drawn on them, a fireplace, a slab, a grave, and placed in linear, L-shaped, or hub-and-spoke layouts. Tokens go on the object the story names. Each exploration reveal is wired to the next.

Bind the Events

Events, tokens, spawns, items, and puzzles are upserted one at a time. Every button, every event1..event6 link, and every localization string is tracked.

Paint the Plates

With a local ComfyUI, generate_artwork paints the cover, an intro cutscene, handouts that hide clues, and the thing on the slab, all in one house style.

Read the Thread

story_graph reads the plot back as one condensed tree, so you and the assistant can check that every branch leads somewhere and every ending can be reached.

Test the Wards

Twenty-one validation rules walk the game as Valkyrie runs it, looking for dead ends, unwinnable scenarios, broken references, unsolvable puzzles and missing text before any player sees them.

Seal the Package

build_scenario saves the files and writes what Valkyrie's own Create Package writes: the .valkyrie archive, its manifest and cover, ready to publish. The scenario is in Valkyrie's editor, ready to play tonight.

Cartography of the unseenSee the Map It Drew

You don't need to open the editor to check the layout. The assistant renders the board with the real tile artwork, exactly as Valkyrie lays it out, with every token numbered. place_tile_relative joins tiles door to door and open ground to open ground, and a ward catches any token that falls off the board or straddles the line between two spaces.

Every tile side, monster, and item is checked against the real game content, so nothing unknown gets into the file.

Every room inventoriedIt Knows What Is in the Room

Every one of the game's tile sides has been charted: where its movement spaces run, which doors lead into which space, and what is painted on the floor. The assistant no longer guesses coordinates. It asks for the tile with a fireplace and a bookcase, and sets the clue on the bookcase rather than beside it.

Herbert West, re-furnished

Asked to improve the placement in Herbert West—Reanimator I, the assistant read the story and moved each token to the thing the text describes. West mixes his solution at the sideboard, in the same room as the slab, not on a ledger in the kitchen. The window the investigators escape through is in the laboratory itself. The grave in the cellar lies open on the bare floor rather than by the coal furnace, and the sexton's satchel waits among the rakes.

It weighed the tiles too. A yard with headstones and a real laboratory both matched the search, but Lovecraft's potter's field has only numbered pine stakes, and West's operating room is improvised in a gasless farmhouse. The overgrown tool-shed yard and the dining table stayed, and the scenario still needs only the base game.

Scenario artworkThe Painted Plates

✦

Every picture below was painted for a scenario by the plugin itself: FLUX.2 [klein] on a local ComfyUI, about thirty seconds a plate, then wired into the scenario where the story needs it.

Cover & cutscene. The scenario list picture, and a full-screen opening with the art beside the story.

Handouts. Letters, clippings and photographs that appear beside the text as they're found, and again whenever an item is inspected.

Picture puzzles. West's torn formula page becomes a sliding-picture puzzle. Solve it and the lab needs one fewer mix.

Set up once. artwork_status checks ComfyUI and the three model files, and prints the exact comfy-cli commands for anything missing.

Validation rulesThe Twenty-One Wards

✦

They follow the game the way Valkyrie runs it, and were tested against community-authored scenarios. A scenario that passes all twenty-one loads and plays as intended.

IRequired FieldsTiles have sides; spawns have monsters.
IICross-ReferencesEvery name referenced actually exists.
IIIEvent GraphNo dead ends, no orphans.
IVLocalizationEvery button and dialog has words.
VFormatCorrect version, type and rotations.
VICatalogTiles, monsters and items are real game content.
VIIMythos StructureThe Mythos phase triggers correctly.
VIIIExplore TokensEach one leads to a reveal.
IXInvestigator TokenPlaced at the start, removed after.
XTile ConnectivityThe house is one house.
XIToken PlacementNo token falls off the board, or between two spaces.
XIIEvent FlowButtons and links agree; silent events behave.
XIIIToken WiringClicking a token does something.
XIVField SchemaNo field Valkyrie would ignore.
XVEvent SemanticsNothing is added and removed at once.
XVICustom ImagesEvery picture and sound exists.
XVIITriggersEvery trigger can actually fire.
XVIIIGame FlowThe game can be won, and lost.
XIXPuzzlesEvery lock can be opened.
XXPackage NameThe package can be published.
XXIUI LifetimeNothing left on screen stalls the next phase.

InstallationThe Summoning

✦

As a Claude Code plugin (the full rite)

Installs the MCP server, all eight skills, and the scenario-designer agent.

$ claude plugin marketplace add thijs-hakkenberg/ValkyrieMCP
$ claude plugin install valkyrie-mom

As a Hermes Agent plugin

Every tool as a native Hermes tool, and the skills as valkyrie-mom:<skill>. Node.js 20+ runs the engine below.

$ hermes plugins install thijs-hakkenberg/ValkyrieMCP --enable

As a bare MCP server (Claude Desktop & other clients)

Only the tools and resources. The grimoire and the familiar need Claude Code or Hermes.

{
  "mcpServers": {
    "valkyrie-mom": {
      "command": "npx",
      "args": ["-y", "@thijshakkenberg/valkyrie-mom-mcp"]
    }
  }
}
