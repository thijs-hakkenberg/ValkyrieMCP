Arkham · Confidential
Arkham, Massachusetts
the 13th of October, 1926

My dear colleague,

You asked me how the scenarios came to be written. I cannot fully explain it. I spoke to the machine of a lighthouse keeper who vanished, of a basement that floods only at the new moon, and of a thing beneath the pier that counts the rounds until it rises.

By morning the file lay in the Editor folder, finished. Every tile was placed and every event branched and joined again. The monster's spawn trigger was tied to the mythos rounds, as I had asked. Not one reference was broken. The validator reported zero errors, and I have never found that comforting.

Valkyrie opened it at once. My players have not slept properly since.

— Prof. H. W. Armitage (ret.)

MCP Tools

The Engine Below

An MCP server that reads and writes Valkyrie's INI and localization files directly and understands the format's quirks.

  • create_scenario, load_scenario, build_scenario
  • upsert_event, tile, token, spawn, item, puzzle, UI
  • delete_component with cascading reference cleanup
  • get_map_ascii, suggest_tile_layout
  • search_game_content over an 846-entry catalog
  • export_bug_report when something goes wrong

From whisper to tableThe Ritual

✦

Speak the Premise

“A fishing village, a missing priest, three hours before high tide.” That much is enough to begin. Invoke /scenario or hand it to the familiar.

Lay the House

Tiles are chosen from the real game catalog and placed in linear, L-shaped, or hub-and-spoke layouts. Each exploration reveal is wired to the next.

Bind the Events

Events, tokens, spawns, items, and puzzles are upserted one at a time. Every button, every event1..event6 link, and every localization string is tracked.

Test the Wards

Twelve validation rules walk the event graph for dead ends, orphans, broken references, and missing text before any player sees them.

Seal the Package

build_scenario saves the INI files and packs the .valkyrie archive. It appears in Valkyrie's editor, ready to play tonight.

Cartography of the unseenSee the Map It Drew

You don't need to open the editor to check the layout. The assistant renders the floor plan as ASCII, computes tile positions relative to one another, and suggests layouts that stay connected. Tile connectivity is one of the wards, so the plugin catches a room that floats off on its own.

Every tile side, monster, and item is checked against the real game content, so nothing unknown gets into the file.

Validation rulesThe Twelve Wards

✦

They were tested against community-authored scenarios. A scenario that passes all twelve loads in Valkyrie as intended.

IUnique NamesNothing shares a name.
IIRequired FieldsTiles have sides; displayed events have buttons.
IIICross-ReferencesEvery name referenced actually exists.
IVEvent GraphStarts at EventStart, no dead ends.
VEvent FlowButtons and links agree; silent events behave.
VILocalizationEvery button and text has words.
VIIFormatCorrect version, type, and rotations.
VIIICatalogTiles, monsters, and items are real game content.
IXTile ConnectivityThe house is one house.
XMythos StructureThe Mythos phase triggers correctly.
XIInvestigator TokenPlaced at the start and removed after.
XIIExplore TokensEach one leads to a reveal.

InstallationThe Summoning

✦

As a Claude Code plugin (the full rite)

Installs the MCP server, all seven skills, and the scenario-designer agent.

$ claude plugin marketplace add thijs-hakkenberg/ValkyrieMCP
$ claude plugin install valkyrie-mom

As a bare MCP server (Claude Desktop & other clients)

Only the tools and resources. The grimoire and the familiar need Claude Code.

{
  "mcpServers": {
    "valkyrie-mom": {
      "command": "npx",
      "args": ["-y", "@thijshakkenberg/valkyrie-mom-mcp"]
    }
  }
}
